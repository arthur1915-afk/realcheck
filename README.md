# REALCHECK — Starter prototype

Responsive landing page and installable PWA shell for the REALCHECK concept.

## Included
- Responsive premium landing page
- Concept description and verification flow
- Privacy and safety principles
- Demo profile card
- Waitlist modal (visual only; does not transmit or store emails)
- PWA manifest and service worker

## Publish with GitHub Pages
1. Open repository Settings → Pages.
2. Under Build and deployment, choose Deploy from a branch.
3. Select branch main and folder /(root), then Save.

## Current status
This is a frontend prototype only. It does not yet include live authentication, identity verification, liveness challenges, messaging, payments, reporting or moderation.

Do not collect or upload government ID documents in this prototype. Use a specialist identity-verification provider and establish consent, retention, deletion, access-control and legal-compliance processes before any real identity data is handled. The demo verified badge is fictional.
